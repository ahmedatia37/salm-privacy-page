1. نبذة عن تطبيق وقتي

تطبيق وقتي هو تطبيق متخصص في توصيل الطلبات داخل محافظة الشرقية – مركز الزقازيق فقط. يتيح التطبيق للمستخدمين طلب المنتجات والخدمات المتاحة من المتاجر ومقدمي الخدمات المشاركين، ومتابعة الطلب حتى إتمام عملية التوصيل.

```

شعار التطبيق هو: «اطلبنا نجيلك دلوقتي».

```

2. المعلومات التي نقوم بجمعها

قد يقوم تطبيق وقتي بجمع بعض المعلومات اللازمة لتقديم خدمة التوصيل، ومنها:

```
  • معلومات الحساب مثل الاسم، رقم الهاتف، والبريد الإلكتروني عند الحاجة.
  • عنوان التوصيل والبيانات اللازمة للوصول إلى المستخدم.
  • معلومات الطلبات والمنتجات التي يتم طلبها من خلال التطبيق.
  • معلومات استخدام التطبيق والميزات التي يتم استخدامها.
  • بيانات تقنية مثل نوع الجهاز ونظام التشغيل ومعرفات الجهاز.
  • بيانات الموقع الجغرافي عند استخدام خدمات تحديد الموقع، وذلك للمساعدة في تحديد موقع التوصيل وتتبع الطلب عند الحاجة.
```

3. استخدام البيانات

نستخدم البيانات التي يتم جمعها للأغراض التالية:

```
  • إنشاء وإدارة حساب المستخدم.
  • استقبال الطلبات ومعالجتها وتنفيذ عمليات التوصيل.
  • تحديد عنوان وموقع التوصيل.
  • التواصل مع المستخدم بخصوص الطلبات والتحديثات المتعلقة بها.
  • تحسين أداء التطبيق وتطوير الخدمات.
  • منع الاستخدام غير المصرح به أو الاحتيالي للتطبيق.
  • الالتزام بالمتطلبات القانونية والتنظيمية.
```

4. خدمات الموقع الجغرافي

قد يحتاج تطبيق وقتي إلى الوصول إلى موقع المستخدم الجغرافي لتحديد عنوان التوصيل وتسهيل وصول الطلب إلى المكان الصحيح.

```

يتم استخدام بيانات الموقع فقط بالقدر اللازم لتقديم خدمات التوصيل وتحسين تجربة المستخدم، ولا يتم بيع بيانات الموقع الشخصية للمستخدمين.

```

5. مشاركة البيانات مع أطراف ثالثة

نحن لا نبيع أو نؤجر البيانات الشخصية للمستخدمين. قد تتم مشاركة بعض البيانات الضرورية مع الأطراف المرتبطة بتنفيذ الطلب، مثل المتجر أو مقدم الخدمة أو مندوب التوصيل، وذلك بالقدر اللازم لإتمام عملية الطلب والتوصيل.

```

كما قد يتم الإفصاح عن البيانات إذا كان ذلك مطلوبًا بموجب القانون أو بناءً على طلب رسمي من الجهات المختصة.

```

6. تسجيل الدخول والحساب

نستخدم بيانات تسجيل الدخول والحساب لتسهيل وصول المستخدم إلى حسابه وإدارة طلباته وحفظ المعلومات اللازمة لتقديم خدمة التوصيل.

```

يتحمل المستخدم مسؤولية الحفاظ على سرية بيانات الدخول الخاصة بحسابه وعدم مشاركتها مع الآخرين.

```

7. حماية البيانات

نستخدم تدابير تقنية وإدارية مناسبة للمساعدة في حماية بيانات المستخدمين من الوصول غير المصرح به أو التعديل أو الإفصاح أو الحذف.

```

ومع ذلك، لا يمكن ضمان أن تكون أي وسيلة إلكترونية لنقل أو تخزين البيانات آمنة بشكل كامل بنسبة 100%.

```

8. ملفات تعريف الارتباط (Cookies)

قد تستخدم بعض خدمات التطبيق أو التقنيات المرتبطة به ملفات تعريف الارتباط أو تقنيات مشابهة لتحسين تجربة المستخدم وتحليل الاستخدام وتطوير الخدمات.

9. نطاق خدمة التوصيل

يقدم تطبيق وقتي خدمات توصيل الطلبات داخل محافظة الشرقية – مركز الزقازيق فقط.

```

قد لا تكون خدمات التطبيق أو التوصيل متاحة خارج النطاق الجغرافي المحدد، ويحق للتطبيق تحديد المناطق التي يمكن تنفيذ الطلبات فيها وفقًا لتوافر الخدمة.

```

10. حقوق المستخدم

يحق للمستخدم، وفقًا للقوانين واللوائح المعمول بها، طلب:

```
  • الوصول إلى بياناته الشخصية.
  • تعديل أو تصحيح بياناته غير الصحيحة.
  • طلب حذف حسابه وبياناته الشخصية، مع مراعاة أي التزامات قانونية تتطلب الاحتفاظ ببعض البيانات.
  • الاستفسار عن كيفية استخدام بياناته.
```
